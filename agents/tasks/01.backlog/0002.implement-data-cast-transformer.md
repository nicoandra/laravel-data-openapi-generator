# Implement Laravel Data cast and transformer adapters

## Objective
Integrate the signed codec with Spatie Laravel Data using its native `Cast` and `Transformer` contracts.

## Expected outcome
Implement paired classes under `src/Data/Cast` and `src/Data/Transformer` that can be registered with `WithCastAndTransformer` and that:

- Transform a supported Data object into the signed base64 string
- Decode and verify the string before hydration
- Resolve the target Data class from the `DataProperty`
- Delegate object hydration and transformation to Laravel Data rather than duplicating its mapping logic
- Produce clear failures for unsupported property types and invalid input

## Evaluation
An integration fixture using `#[WithCastAndTransformer(...)]` successfully round-trips a nested Data object through `Data::from()` and `transform()`. Tests confirm the adapter delegates to Laravel Data, preserves supported nullable behavior, and rejects incompatible target types without bypassing signature verification.
