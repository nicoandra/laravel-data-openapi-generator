# Document wire format and usage

## Objective
Document how consumers and maintainers use the signed-string Data feature and what security or compatibility guarantees it provides.

## Expected outcome
Repository documentation includes:

- Registration and property examples
- Encode/decode lifecycle
- Wire-format example
- Key configuration requirements
- Failure behavior
- Replay and expiration limitations
- Key rotation/versioning guidance
- OpenAPI representation and limitations
- URL, query, and transport considerations

Documentation is consistent with the implemented contract and existing project conventions.

## Evaluation
A new contributor can configure and use the cast/transformer and understand the generated OpenAPI output without reading implementation details. The examples are validated against the final API and all documented guarantees are covered by tests or explicitly marked as non-guarantees.
