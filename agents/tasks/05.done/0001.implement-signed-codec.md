# Implement the signed payload codec

## Objective
Implement isolated signing, envelope, JSON, base64, and expiration logic without coupling it to Spatie Laravel Data interfaces.

## Expected outcome
A reusable codec/service that can:

- Encode deterministic JSON into a versioned signed envelope
- Include issued-at and expiration timestamps in the signed data
- Use a default token TTL of one week from package configuration
- Accept an optional per-cast TTL override, such as a CarbonInterval-parseable string
- Base64-encode the envelope for transport
- Strictly decode and validate base64
- Verify signatures with constant-time comparison before trusting payload data
- Reject expired, malformed, tampered, unsupported-version, and oversized payloads according to the wire contract

Use the configured Laravel application key as the signing secret according to the agreed key-handling rules. Define how `null`, zero, and invalid TTL overrides behave; do not silently create non-expiring tokens.


## Evaluation
Unit tests prove successful round trips, default one-week expiration, valid custom TTL overrides, expired tokens, invalid TTL configuration, and rejection of wrong keys, altered payloads, altered signatures, malformed base64, malformed envelopes, invalid JSON, unsupported versions, and unsupported key formats. The codec has no dependency on `Cast` or `Transformer` interfaces.
