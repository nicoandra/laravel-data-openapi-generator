# Add round-trip and failure regression coverage

## Objective
Build focused regression coverage for the complete signed Data value lifecycle.

## Expected outcome
Tests cover:

- Simple and nested Data objects
- Repeated and deterministic transformations
- Null and optional values where supported
- Tampered payloads and signatures
- Wrong signing keys
- Invalid base64, envelopes, and JSON
- Unsupported Data target types
- Laravel `app.key` values, including the configured key format
- Boundary and size-limit behavior defined by the wire contract

## Evaluation
The test suite fails when signing, verification ordering, hydration, or deterministic serialization is broken. Tests use repository fixtures under `tests/Dummy` and follow existing Pest conventions. The full relevant test suite passes after implementation.
